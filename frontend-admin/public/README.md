# Assets statiques

Ce dossier contient les fichiers statiques de l'application.

## Fichiers requis

1. **logo.png** - Logo de l'association IGCA Paris
   - Format : PNG avec fond transparent ou fond blanc
   - Taille recommandée : 200x200px minimum
   - À placer dans ce dossier pour être accessible via `/logo.png`

2. **favicon.png** - Favicon de l'application
   - Format : PNG (ou ICO)
   - Taille recommandée : 32x32px ou 64x64px
   - À placer dans ce dossier pour être accessible via `/favicon.png`

## Utilisation

Les fichiers placés dans ce dossier sont servis directement par Vite et sont accessibles via des chemins absolus commençant par `/`.

Exemple :
- `/logo.png` → `public/logo.png`
- `/favicon.png` → `public/favicon.png`
