# Frontend Admin IGCA Paris - Vue.js

Interface d'administration web pour IGCA Paris développée avec Vue.js 3.

## Technologies

- Vue.js 3 (Composition API)
- TypeScript
- Vue Router 4
- Pinia (gestion d'état)
- Axios
- Vite

## Installation

```bash
npm install
```

## Démarrage

```bash
npm run dev
```

L'application sera accessible sur http://localhost:3000

## Structure

```
src/
├── assets/         # Fichiers statiques (CSS, images)
├── layouts/        # Layouts (MainLayout)
├── router/         # Configuration Vue Router
├── services/       # Services API (axios)
├── stores/         # Stores Pinia (auth)
├── types/          # Types TypeScript
└── views/          # Pages/Vues
```
