## ✨ Animations & Transitions

### Durées
- **Fast**: `0.15s` - Micro-interactions
- **Base**: `0.2s` - Transitions standards
- **Slow**: `0.3s` - Animations complexes

### Easing
- **Ease Out**: `cubic-bezier(0.4, 0, 0.2, 1)`
- **Ease In Out**: `cubic-bezier(0.4, 0, 0.6, 1)`

### Animations Courantes
- **Fade In**: Opacité 0 → 1
- **Slide Up**: Transform translateY(10px) → 0
- **Scale**: Transform scale(0.95) → 1
- **Hover Lift**: Transform translateY(-2px) + ombre

## 🎨 États des Composants

### Hover
- Légère élévation
- Changement de couleur subtil
- Transition fluide

### Active
- Légère pression visuelle
- Couleur plus foncée
- Scale légèrement réduit

### Disabled
- Opacité: 50%
- Cursor: not-allowed
- Pas d'interaction

### Loading
- Spinner animé
- Opacité réduite
- Cursor: wait

## 📋 Checklist de Design

### Avant de créer un composant
- [ ] Utiliser les couleurs de la palette
- [ ] Respecter les espacements standards
- [ ] Appliquer les border radius appropriés
- [ ] Ajouter les états hover/active/disabled
- [ ] Vérifier le contraste d'accessibilité
- [ ] Tester sur mobile et desktop
- [ ] Ajouter les transitions appropriées

### Principes Généraux
- **Warmth**: Toujours privilégier la chaleur et l'accueil
- **Elegance**: Design raffiné mais accessible
- **Consistency**: Cohérence dans tous les composants
- **Clarity**: Communication claire et directe
- **Delight**: Petites touches qui rendent l'expérience agréable
